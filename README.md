A program that sums up Thursday 19 November 2026 world news in one image: the Trump, Xi and Putin summit in Shenzhen, the ICJ Rohingya ruling, Gaza, Ukraine, Hormuz and Bangladesh. Pure Python standard library only, it draws a 1024x1024 newspaper front page and writes it to /output/entry.png, byte-identical on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
